## 🚀 Quick Start

After creating a repository from this template:

### 1. Clone Your New Repository
```bash
git clone <your-new-repo-url>
cd <your-new-repo>
```

### 2. Run the Branch Setup Script
```bash
bash setup-branches.sh
```

**⚠️ Important:** This step is required! Without it, branches cannot be merged due to a GitHub template limitation.

### 3. Start Working

Your branches are now properly configured and ready to use!

## 📋 Branch Structure

- **`develop`** - Main development branch (default)
- **`release`** - Staging/pre-production testing
- **`prod`** - Production releases

## 🔄 Workflow
